Install in a minute

Lamplore lives on GitHub, not an app store.

Download the APK

Tap Download above, or grab lamplore.apk from the latest release.

Allow the install

Open the file. When Android asks, allow your browser or file manager to install unknown apps.

Press play

Optional: add better offline voices in Settings. Everything else works straight away.

Questions


Is it really free?

Yes. No ads, no subscription, no sign-up. Audiobooks and podcasts come from LibriVox, the Internet Archive and podcast feeds that are free to stream.

Is it safe to install outside the Play Store?

The full source is in this repository and every release is built from it. You can read it, build it yourself, or skip it.

Does it work offline?

Yes for anything you download, and for the built-in stories with on-device voices. Streaming needs a connection.

Is it religious?

No. Lamplore is secular: fables, wisdom tales from many cultures, classics and sleep stories.

iPhone?

Not planned. Android only for now.

How do I update?

Download the newest APK and install it over the old one. Your history and downloads stay.
